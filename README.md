# ASCII Art to C String Converter

A small C utility that reads a file containing raw ASCII art and generates a C source snippet containing a ready-to-use `const char *` string variable with a `printf()` call.

## What it does

Given an ASCII art file like:

```
  /_\_/  \
 ( o.o ) 
  > ^ <  
```

It produces a C-compatible output file containing:

```c
const char *ascii_art =
    "  /_\\_/  \n"
    " ( o.o ) \n"
    "  > ^ <  \n";

// Example usage:
printf("%s", ascii_art);
```

## Building

```bash
gcc -o ascii_to_c main.c
```

## Usage

```bash
./ascii_to_c <input_art.txt> <output.txt> [variable_name]
```

### Arguments

| Argument | Description |
|----------|-------------|
| `input_art.txt` | Path to the file containing raw ASCII art |
| `output.txt` | Path for the generated C string output |
| `variable_name` | *(optional)* Name for the C variable. Defaults to `ascii_art` |

### Example

```bash
# Basic usage (variable name defaults to "ascii_art")
./ascii_to_c input_art_example.txt output_example.txt

# Custom variable name
./ascii_to_c logo.txt logo.c my_logo
```

## Output format

Each line of the input is converted into a separate quoted C string literal with:

- Proper escaping of `\`, `"`, and `\t`
- Automatic `\n` appended to each line
- Stray `\r` characters (from CRLF files) are stripped
- A `printf()` example is appended at the bottom for convenience

## Demo

`usage.c` is a complete C program generated by this tool — it displays ASCII art when compiled and run:

```bash
gcc -o usage-compiled usage.c
./usage-compiled
```

It's a great example of the kind of output the converter produces.
